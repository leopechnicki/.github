# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, **do not open a public issue**.

Please report it privately by emailing **leopsantos@hotmail.com** with:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

I'll acknowledge within 48 hours and work on a fix as quickly as possible.

## Scope

This policy applies to all public repositories under [leopechnicki](https://github.com/leopechnicki).
